# Controllers

This directory contains the controllers for the game. The controllers are the brains behind entities on the map.

## Aggressive Controller

This controller's strategy is the most chaotic and simplistic. It will select the nearest entity not controlled by its controller, move toward it and attack it relentlessly. It will not stop until the entity is dead or the controller is dead.
