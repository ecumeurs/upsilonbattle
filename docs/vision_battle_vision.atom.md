# Upsilon Battle Engine Vision

## INTENT
Define the vision for the Upsilon Battle Engine as the uncompromising deterministic core of the TRPG.

## THE RULE / LOGIC
- **Core Objective:** Simulate tactical combat with mathematical precision and absolute determinism.
- **Key Features:**
  - **Dynamic Initiative:** A delay-based ticker system that replaces traditional turn orders with a non-linear temporal flow.
  - **Grid-Based Tactics:** Procedural board generation and strict movement/range validation.
  - **Stat Scaling:** Robust stat system with meaningful percentage modifiers and progression.
- **Isolation:** The engine must remain agnostic of network protocols and persistence, focusing entirely on logic.
